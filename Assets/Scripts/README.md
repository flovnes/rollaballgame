# Оновлення гри "Roll a Ball"

Цей проект містить наступні покращення для отримання максимального балу за завдання:

## 1. Додаткові ігрові механіки
Реалізовано дві унікальні механіки:
- **Зміна розміру (Size Shifting)**: 
    - Натискання **'R'** — збільшує кульку (стає важчою, легше штовхати ворогів/коробки, але рухається повільніше). Колір змінюється на синій.
    - Натискання **'F'** — зменшує кульку (стає легкою та дуже швидкою, легше маневрувати). Колір змінюється на зелений.
    - Натискання **'T'** — повертає стандартний розмір.
- **Стрибок (Jump)**: Натискання клавіші **'Space'** дозволяє кульці підстрибувати для уникнення ворогів або подолання перешкод.
- **Ривок (Dash)**: Натискання клавіші **'Shift'** дає миттєве прискорення у напрямку руху, що критично для втечі від ворога.

## 2. Ускладнення середовища
- Створено скрипт `Oscillator.cs`, який дозволяє будь-якому об'єкту (стіни, платформи) рухатися автоматично. Це додає динамічні перешкоди, які гравець повинен оминати.

## 3. Меню та інтерфейс
- **Стартове меню**: Гра починається з паузи та вікна привітання.
- **Меню завершення**: Після перемоги або програшу з'являється вікно зі статусом гри та кнопкою **Restart** для швидкого перезапуску.

## 4. Візуальні та звукові ефекти
- У коді додано хуки для програвання звуків під час збору бонусів, стрибків та зміни гравітації.
- Додано систему частинок (Particles) при підбиранні предметів.
